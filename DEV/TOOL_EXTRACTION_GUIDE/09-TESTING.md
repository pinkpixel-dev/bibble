# ✅ Testing Guide

*Practical, runnable patterns to verify the standalone Desktop Commander tools in your TypeScript app*

---

## 🎯 Goal
Provide lightweight, framework-agnostic testing patterns you can run with Node, plus Jest examples if you prefer a test runner.

## 🧰 What You'll Test
- Filesystem tools: read/write/list/info, URLs, line limits
- Process tools: start/interact/read/terminate, REPLs
- Search tools: code search, file search, sessions, pagination
- Edit tools: exact + fuzzy replacements, diffs, multi-occurrences
- Configuration & analytics: defaults, overrides, usage tracking

---

## 1) Zero-dep Node test scripts (fastest to try)

Create a directory `tests/manual/` in your project and drop these files in. Run with: `node tests/manual/<file>.mjs` (or ts-node if using TS directly).\n
### a) Filesystem smoke test (tests/manual/fs-smoke.mjs)\n```javascript\nimport { join } from 'node:path';\nimport { tmpdir } from 'node:os';\nimport { writeFile, readFile, createDirectory, getFileInfo, listDirectory } from '../../src/desktop-commander/tools/filesystem.js';\n\nconst t = async () => {\n  const base = join(tmpdir(), 'dc-fs-' + Date.now());\n  console.log('Base dir:', base);\n  \n  const d = await createDirectory(base);\n  console.log('createDirectory:', d);\n  \n  const file = join(base, 'hello.txt');\n  const w = await writeFile(file, 'Hello\nWorld');\n  console.log('writeFile:', w);\n  \n  const r = await readFile(file, { offset: 0, length: 10 });\n  console.log('readFile:', r.success, r.data?.lineCount, r.data?.content);\n  \n  const info = await getFileInfo(file);\n  console.log('getFileInfo:', info);\n  \n  const l = await listDirectory(base);\n  console.log('listDirectory:', l.data?.length);\n};\n\nawait t();\n```\n
### b) Process smoke test (tests/manual/process-smoke.mjs)\n```javascript\nimport { startProcess, interactWithProcess, readProcessOutput, forceTerminate } from '../../src/desktop-commander/tools/process.js';\n\nconst run = async () => {\n  const p = await startProcess(process.platform === 'win32' ? 'powershell' : 'bash', 10000);\n  console.log('startProcess:', p.success, p.data?.pid);\n  if (!p.success || !p.data) return;\n  const { pid } = p.data;\n\n  await interactWithProcess(pid, 'echo START');\n  const out1 = await readProcessOutput(pid, 3000);\n  console.log('readProcessOutput(1):', out1.data?.output);\n\n  await interactWithProcess(pid, 'pwd');\n  const out2 = await readProcessOutput(pid, 3000);\n  console.log('readProcessOutput(2):', out2.data?.output);\n\n  await forceTerminate(pid);\n};\n\nawait run();\n```\n
### c) Search smoke test (tests/manual/search-smoke.mjs)\n```javascript\nimport { quickSearch, startSearch, getSearchResults, getSearchStatus } from '../../src/desktop-commander/tools/search.js';\nimport { resolve } from 'node:path';\n\nconst root = resolve('.');\n\nconst run = async () => {\n  // Quick search\n  const quick = await quickSearch(root, 'Desktop Commander|desktop-commander', { searchType: 'code', ignoreCase: true, maxResults: 20 });\n  console.log('quickSearch:', quick.success, quick.data?.length);\n\n  // Session search\n  const start = await startSearch(root, 'import ', { searchType: 'code', ignoreCase: true, maxResults: 100 });\n  console.log('startSearch:', start);\n  if (!start.success || !start.data) return;\n\n  const sid = start.data;\n  let status;\n  do {\n    await new Promise(r => setTimeout(r, 300));\n    const st = await getSearchStatus(sid);\n    status = st.data;\n    console.log('status:', status?.status, status?.totalCollected);\n  } while (status && status.status === 'running');\n\n  const page = await getSearchResults(sid, 0, 10);\n  console.log('getSearchResults:', page.data?.items?.length);\n};\n\nawait run();\n```\n
### d) Edit smoke test (tests/manual/edit-smoke.mjs)\n```javascript\nimport { join } from 'node:path';\nimport { tmpdir } from 'node:os';\nimport { writeFile as fsWriteFile } from 'node:fs/promises';\nimport { editBlock } from '../../src/desktop-commander/tools/edit.js';\n\nconst run = async () => {\n  const base = join(tmpdir(), 'dc-edit-' + Date.now());\n  const file = join(base, 'note.md');\n  await fsWriteFile(file, 'Line A\nLine B\nLine C\n');\n\n  const res1 = await editBlock({ filePath: file, oldString: 'Line B', newString: 'Line B (edited)' });\n  console.log('editBlock exact:', res1);\n\n  const res2 = await editBlock({ filePath: file, oldString: 'Line X', newString: 'Line X (new)' });\n  console.log('editBlock fuzzy (expected 0 or fuzzy result):', res2);\n};\n\nawait run();\n```\n

## 2) Jest-style tests (optional)\nAdd Jest and ts-jest if your project uses it:\n```bash\nnpm install -D jest ts-jest @types/jest\nnpx ts-jest config:init\n```\n
Example: tests/filesystem.test.ts\n```typescript\nimport { join } from 'path';\nimport { tmpdir } from 'os';\nimport * as fsTools from '../src/desktop-commander/tools/filesystem.js';\n\ndescribe('Filesystem tools', () => {\n  const base = join(tmpdir(), 'dc-jest-' + Date.now());\n\n  it('writes and reads files', async () => {\n    await fsTools.createDirectory(base);\n    const file = join(base, 'x.txt');\n    await fsTools.writeFile(file, 'a\nb\nc');\n    const r = await fsTools.readFile(file, { length: 2 });\n    expect(r.success).toBe(true);\n    expect(r.data?.lineCount).toBe(2);\n  });\n});\n```\n

## 4) Tips\n- Prefer temporary directories via `os.tmpdir()` for write tests\n- On Windows, prefer PowerShell (`powershell`) for interactive process tests\n- For flaky long-running tests, increase timeouts and add retries\n- Use small test files for edit/search stress cases first, then scale up\n\n## 5) CI Hints\n- Skip interactive process tests in CI unless you control the runner\n- Gate ripgrep-dependent tests behind an environment variable if needed\n- Persist logs (`~/.desktop-commander-logs`) as CI artifacts for debugging\n\n---\n\nHappy testing!\n
